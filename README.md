# T20 Hibah & Waqf Planner

## Jalankan
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy Vercel
Import folder/repository ini ke Vercel. Framework preset: Vite. Build command: `npm run build`. Output: `dist`.

## Nota
MVP ini sengaja tidak menyimpan data prospek. Semua pengiraan berlaku dalam browser.
Untuk produksi: sahkan formula/manfaat dengan operator takaful dan penasihat pematuhan, gunakan ikon PNG 192/512 jika platform sasaran memerlukan PNG, dan tambah auth/database hanya selepas keperluan komersial disahkan.
